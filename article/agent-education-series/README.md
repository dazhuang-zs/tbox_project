# 【AI Agent 系统教学】课程大纲

> 从大模型原理到多 Agent 应用，构建完整的 Agent 知识体系
> 预计总篇数：40+ 篇

---

## 课程定位

本系列不是零碎的博客文章，而是一套**系统化的技术教学课程**，面向：
- 有一定编程基础、想深入理解 Agent 技术栈的开发者
- 正在从传统开发转向 AI 开发的工程师
- 想系统学习而非零散搜集碎片知识的技术人

## 课程结构（7 大模块 + 番外）

```
模块一：大模型底层原理       → 知其然，更知其所以然
模块二：提示词工程体系       → 与模型沟通的完整方法论
模块三：RAG 技术深度解析     → 知识增强的检索生成
模块四：Agent 范式与架构     → 从 LLM 到 Agent 的跨越
模块五：Agent 核心能力系统   → 记忆、工具、规划、安全
模块六：多 Agent 系统        → 协作、通信、编排
模块七：Agent 未来与生态     → 趋势、经济、AGI 之路
番外：实战与深度专题         → 论文解读、框架对比、踩坑记录
```
