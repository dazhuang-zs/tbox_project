# 鸿蒙开发系列专栏设计

## 基本信息
- 专栏名称：《从零到实战：ArkTS + ArkUI 鸿蒙应用开发实战指南》
- 目标读者：零基础编程小白
- 技术栈：ArkTS + ArkUI（HarmonyOS 6.0 / API 23）
- 篇数：5 篇
- 风格：保姆级教程，每篇配代码 + 截图 + 完整项目地址

---

## 系列大纲（从简到繁，循序渐进）

### 第 1 篇：环境搭建 + Hello World
**目标**：让读者把开发环境跑起来，写出第一个鸿蒙 App

**内容**：
- HarmonyOS 是什么？ArkTS、ArkUI 是什么关系？
- 安装 DevEco Studio（Windows/Mac 完整指南 + 截图）
- 配置 SDK、模拟器/真机调试
- 创建第一个项目，分析项目结构
- 写一个「Hello 鸿蒙」页面，理解 EntryAbility
- 常见坑 & 解决方案（安装报错、模拟器启动不了等）

**亮点**：降门槛，让零基础读者 30 分钟内跑通

---

### 第 2 篇：ArkTS 语法速通 + UI 基础组件
**目标**：掌握 ArkTS 核心语法，能做简单页面布局

**内容**：
- ArkTS 与 TypeScript/JavaScript 的关系，快速上手
- 核心数据类型、变量、函数、条件、循环
- 常用 UI 组件：Text、Button、Image、Column、Row
- Flex 布局 + 响应式适配
- 实战：做一个「个人名片」页面（头像+名字+简介+技能标签）

**亮点**：不枯燥讲语法，边学边做

---

### 第 3 篇：数据持久化 + 本地存储实战
**目标**：学会存数据、读数据，做一个真正「有用」的 App

**内容**：
- ArkTS 状态管理：@State、@Prop、@Link
- 本地存储方案：Preferences / 关系型数据库
- 列表组件 List + ForEach 渲染
- 交互：TextInput、弹窗、Toast
- 实战：做一个「待办清单」App（增删改查 + 数据持久化）

**亮点**：从静态页面到有状态 App 的跨越

---

### 第 4 篇：网络请求 + 数据展示
**目标**：学会调接口、解析数据、展示列表

**内容**：
- HTTP 请求基础（@ohos.net.http）
- JSON 解析与数据模型
- 下拉刷新 + 上拉加载
- 导航与页面跳转（Router）
- 实战：做一个「GitHub 热门项目浏览器」（搜索+列表+详情页）

**亮点**：接入真实 API，做出联网 App

---

### 第 5 篇：AI 能力集成 + 完整项目
**目标**：结合大模型 API，完成有 AI 能力的完整 App

**内容**：
- 调用 AI API（如 DeepSeek/ChatGPT 接口）的方法
- 流式输出（SSE）的实现
- 鸿蒙权限管理（网络权限、敏感权限）
- 性能优化小技巧
- 打包发布到真机
- 实战：做一个「AI 聊天助手」App（对话历史 + 流式回复 + Markdown 渲染）

**亮点**：结合当下最热 AI 话题，项目有展示价值

---

## 每篇统一结构

```
1. 开篇语：这篇文章要做什么？（痛点 + 效果图预览）
2. 前置准备：读完前 N 篇 / 需要的环境
3. 核心内容拆解（3-5 个步骤，每步配代码）
4. 完整代码 / GitHub 项目地址
5. 效果展示（截图/GIF/动图）
6. 常见问题 & 踩坑记录
7. 总结 + 下篇预告
```

- **梯度合理**：UI → 数据 → 网络 → AI，每一步都有新技能
- **实战驱动**：每篇都有一个完整可运行的小项目
