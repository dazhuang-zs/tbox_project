## 开篇：为什么你之前看PS教程总学不会？

我2016年第一次打开Photoshop，盯着那个密密麻麻的界面看了10分钟，默默地关掉了。

后来强迫自己学了三个月，才搞明白一件事：**大多数教程犯了一个致命错误——一上来就教你怎么用某个工具做个炫酷效果。**

问题是，你连图层是什么都不知道，连"为什么我移动不了这个文字"都搞不明白，上来就做特效，当然一头雾水。

本文换一个思路：**先让你理解PS的"操作系统"，再教具体功能。**

就像学开车——不是一上来就教你漂移，而是先让你认识方向盘、油门、刹车各自是干什么的。看完这篇，你至少不会打开PS后一脸懵。

### 1.2 五个核心区域 — 逐一说清楚

#### 区域1：菜单栏（顶部的字）

所有的功能最终都能在这里找到。你不用背，只需要知道怎么找：

#### 区域3：选项栏（菜单栏下方横条）

**这个东西很多人忽略，但它特别重要！**

选项栏会根据你当前选中的工具**自动变化**。比如：

- 你选**文字工具** → 选项栏出现字体、字号、颜色、对齐方式
- 你选**画笔工具** → 选项栏出现笔刷大小、硬度、不透明度
- 你选**矩形选框** → 选项栏出现羽化值、样式（正常/固定比例/固定大小）

**关键操作**：如果你发现某个工具"怎么调都调不好"，先看选项栏！90%的工具设置都在这。

## 第二章：10个你必须先会的基础操作

### 操作1：新建文件

```
菜单栏 → 文件 → 新建  （快捷键 Ctrl+N）

弹出窗口里要填的：
┌────────────────────────────┐
│  名称：公众号封面             │ ← 文件名
│  宽度：900   像素           │ ← 单位可以改成厘米/英寸/像素
│  高度：383   像素           │
│  分辨率：72  像素/英寸      │ ← 屏幕用72，印刷用300
│  颜色模式：RGB 颜色         │ ← 屏幕显示用RGB，印刷用CMYK
│  背景内容：白色             │ ← 白色/透明/背景色
└────────────────────────────┘
```

**关键概念：分辨率到底是什么？**

- **72 PPI（屏幕用）**：每英寸72个像素点。电脑屏幕、手机屏幕够用了，文件小。
- **300 PPI（印刷用）**：每英寸300个像素点。打印出来才清晰，文件大。
- **简单记法**：只在屏幕上看 → 72；要打印出来 → 300

**关键概念：RGB vs CMYK**

- **RGB**（红绿蓝）：光的叠加，所有屏幕都用这个。选这个。
- **CMYK**（青品黄黑）：油墨的叠加，印刷厂用。你如果要做海报送印刷店才选它。
- **99%的情况下你选RGB就对了。**

### 操作2：打开文件

```
方式1：菜单栏 → 文件 → 打开 → 选择图片
方式2：直接把图片文件拖进PS窗口
方式3：Ctrl+O
```

### 操作3：保存文件（这个很多人搞错！）

PS有两种"保存"：

| 操作 | 路径 | 格式 | 用途 |
|------|------|------|------|
| **保存** | 文件 → 存储 (Ctrl+S) | .PSD | 保留所有图层，下次能继续编辑 |
| **导出** | 文件 → 导出 → 导出为 (Ctrl+Shift+S) | .PNG / .JPG | 给别人看、发朋友圈、上传网站 |

> ⚠️ **新手最容易犯的错**：做了半天的图，直接Ctrl+S存成了PSD，微信发不出去。
> **正确做法**：编辑中的文件存PSD；给别人看的导出PNG或JPG。

**PNG vs JPG 什么时候用哪个？**

| 格式 | 特点 | 用在哪 |
|------|------|--------|
| **PNG** | 支持透明背景、无损、文件较大 | 需要透明背景（logo、贴纸）、文字多的图 |
| **JPG** | 不支持透明、有损压缩、文件小 | 照片、不需要透明背景的图 |
| **PSD** | Photoshop专用、保留图层 | 自己留着继续编辑 |

### 操作4：缩放画布（看清细节/看全图）

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 放大 | `Ctrl + +` | 或者按住Alt+鼠标滚轮向上 |
| 缩小 | `Ctrl + -` | 或者按住Alt+鼠标滚轮向下 |
| 适应窗口 | `Ctrl + 0` | 画布刚好铺满窗口，最常用！ |
| 100%大小 | `Ctrl + 1` | 实际像素，查看细节 |
| 抓手拖动画布 | **按住空格键** + 鼠标拖动 | 放大后移动视野（最常用！） |

> 💡 **最常用的组合**：滚轮缩放 + 空格键拖动。右手滚轮，左手空格，无缝切换。

### 操作5：撤销（做错了怎么办）

| 操作 | 快捷键 | 区别 |
|------|--------|------|
| 撤销一步 | `Ctrl + Z` | 撤销上一次操作 |
| 撤销多步 | `Ctrl + Alt + Z` | 连续按一直往回退 |
| 重做 | `Ctrl + Shift + Z` | 撤销的反操作 |
| 历史记录面板 | 窗口 → 历史记录 | 可以看到所有操作记录，点任意一步跳回去 |

### 操作6：自由变换——缩放、旋转、变形

这是Photoshop使用频率最高的功能，没有之一。

```
1. 在图层面板中选中你要变换的图层
2. Ctrl + T （或 菜单 → 编辑 → 自由变换）
3. 图片四周出现8个小方块（控制点）

这时你可以：
┌───────────────────────────────┐
│  拖动四角控制点  →  缩放大小    │
│  按住Shift拖角   →  等比例缩放  │ ← 防止变形！一定要按Shift
│  拖动边上的控制点  →  拉伸       │
│  鼠标放角外面    →  旋转        │
│  按住Shift旋转   →  每次15°旋转 │
│  右键选"水平翻转" →  镜像翻转    │
│  按Enter         →  确认变换    │
│  按Esc           →  取消变换    │
└───────────────────────────────┘
```

### 操作7：复制图层（做图必备习惯）

**方式1：快捷键**
```
在图层面板选中图层 → Ctrl + J → 原地复制一层
```

**方式2：拖动**
```
在图层面板中，把图层拖到"新建图层"按钮上（📄图标）
```

**方式3：右键**
```
在图层上右键 → 复制图层
```

> ⚠️ **黄金法则：动原图前先Ctrl+J复制一层！** 在原图上直接操作，做坏了只能重来。复制一层再改，原图永远在底层保留。

### 操作8：图层可见性

```
图层面板中每个图层左边都有个👁眼睛图标
点一下眼睛 → 图层隐藏（不显示，但还在）
再点一下 → 图层显示

用途：
- 做图时对比"有这个元素 vs 没有"的效果
- 暂时隐藏挡住的图层方便操作下面的
```

### 操作9：图层顺序

```
在图层面板中，直接用鼠标拖动图层上下移动。
上面的图层会挡住下面的。

类比：图层像一叠透明玻璃板，你在最上面的玻璃上画东西，会挡住下面玻璃上的内容。
```

### 操作10：选中图层上的内容

```
重要区分：
- 在图层面板中点图层名 → 选中了整个图层（可以移动/变换）
- 按住Ctrl + 点图层的缩略图 → 按内容形状创建选区（用于抠图操作）
```

## 第三章：图层——PS的灵魂，你必须彻底搞懂

### 3.1 什么是图层？（用生活场景理解）

想象你桌上放了3张透明塑料片：

```
┌──────────────────────┐
│  第3张：写了"你好"      │ ← 文字图层
├──────────────────────┤
│  第2张：画了个红色圆形   │ ← 形状图层
├──────────────────────┤
│  第1张：贴了一张照片     │ ← 图片图层
└──────────────────────┘
         ↓ 从上方看

结果你看到的是：照片上压着一个红色圆形，圆形上面又有"你好"两个字。

如果你：
- 移动第3张 → "你好"两个字的位子变了，下面都不受影响
- 擦掉第2张的红色圆形 → 下面照片完好无损
- 把第3张抽掉 → "你好"消失了，但照片和红圆还在
```

**这就是图层：每一个元素在独立的"层"上，修改一层不影响其他。**

### 3.2 图层类型——你建的都是哪一种？

| 图层类型 | 怎么创建 | 里面有什么 | 特点 |
|---------|---------|-----------|------|
| **普通图层** | Ctrl+Shift+N 或点📄按钮 | 透明的，什么都没有 | 最通用的图层 |
| **文字图层** | 点T工具然后输入文字 | 文字内容，可以随时编辑 | 图层面板显示T图标 |
| **形状图层** | 用矩形/椭圆等工具画 | 矢量形状，放大不失真 | 可以随时改形状和颜色 |
| **调整图层** | 点图层面板底部的◐按钮 | 调色指令 | 不改原图！只影响下面的图层 |
| **智能对象** | 右键图层→转换为智能对象 | 受保护的原图 | 缩放不失真，滤镜可修改 |

### 3.3 调整图层——为什么它是调色的正确姿势

**错误做法**：直接在照片图层上 → 菜单 → 图像 → 调整 → 亮度对比度
→ 原图被改了，想恢复只能撤销。

**正确做法**：
```
1. 点图层面板底部的◐按钮（创建新的填充或调整图层）
2. 选择"亮度/对比度"
3. 弹出一个属性面板，拖动滑块调整
4. 不满意？直接删掉这个调整图层，照片完好无损
5. 想让效果只对部分区域生效？给调整图层加个蒙版（进阶）
```

**可用的调整类型**（每个都能独立开关、调整参数）：
- 亮度/对比度 — 整体明暗
- 色阶 — 精确控制暗部/亮部/中间调
- 曲线 — 最强大的调色工具（进阶）
- 色相/饱和度 — 改变颜色和鲜艳度
- 色彩平衡 — 修正色偏
- 黑白 — 彩色变黑白

### 3.4 图层混合模式和不透明度

**不透明度**：在图层顶部，0%=完全透明，100%=完全不透明。

```
用途：
- 做水印文字 → 调到 30%
- 加光影效果 → 用白色画笔在新图层上画，降低不透明度
- 做倒影 → 复制一层，翻转，不透明度 30%
```

**混合模式**（不透明度旁边）：决定当前图层和下面图层怎么混合。新手先记住两个：

| 模式 | 效果 | 用在哪 |
|------|------|--------|
| **正片叠底**（Multiply） | 变暗，白色变透明 | 叠加纹理、去掉白底 |
| **滤色**（Screen） | 变亮，黑色变透明 | 叠加光效、去掉黑底 |

### 3.5 图层蒙版——"用橡皮擦但不真的擦"

这是从新手到进阶最关键的一步。先看场景：

**你想让照片的边缘渐变消失（羽化效果）。**

❌ 错误做法：橡皮擦直接擦 → 擦完就没了，改不了。
✅ 正确做法：给图层加蒙版 → 用黑画笔在蒙版上涂 → 涂的地方隐藏。想恢复？换白画笔涂回来。

```
操作步骤：
1. 选中图层
2. 点图层面板底部的"添加图层蒙版"按钮（□○图标）
3. 图层旁边出现一个白色的方块（这就是蒙版）
4. 选画笔工具（B），前景色设为黑色
5. 在你想隐藏的地方涂抹 → 涂过的地方"消失"了
6. 前景色换成白色 → 再涂 → "消失"的部分又回来了

核心规则：
- 蒙版上涂黑色 = 隐藏该区域
- 蒙版上涂白色 = 显示该区域
- 蒙版上涂灰色 = 半透明

蒙版不破坏原图！你只是在"遮住"而不是"删除"。
```
