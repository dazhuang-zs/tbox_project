# 人类第一台电脑为什么是庞然大物——从30吨的ENIAC到你口袋里的手机，中间发生了三件事

> **摘要**：1946年诞生的ENIAC重30吨、占地170平方米、用了18000根真空管，但算力还不如你手上一个5块钱的计算器。仅仅80年后，一台手机的算力是它的100亿倍，重量只有它的百万分之一。这中间到底发生了什么？本文从三个技术跃迁——真空管到晶体管、晶体管到集成电路、集成电路到芯片——讲清楚"为什么电脑从一间房变成一块芯片"的完整故事。不是科普词条，是带着数据和时间线的硬核科技史。

## 开篇：你家WiFi路由器的算力，是ENIAC的50万倍

1946年2月，世界上第一台通用电子计算机ENIAC在宾夕法尼亚大学揭幕。

它的性能参数是这样的：
- 每秒5000次加法运算
- 重30吨
- 占地170平方米（相当于一套三室一厅的房子）
- 耗电150千瓦（运行一次，费城西区的灯都要闪一下）
- 用了18000根真空管（真空管每两天烧一根，当时专门雇了一个团队换管子）

给你一个直观对比：**2026年你手上5块钱买的科学计算器，每秒能做至少50万次运算——是ENIAC的100倍。而一个四核手机芯片，每秒约250亿次，是ENIAC的5000万倍。**

这不是科幻。这是三代技术革命在80年内完成的事情。

## 一、ENIAC到底长什么样——30吨的"电脑"里装了啥

### ENIAC的结构

ENIAC不是一个"盒子"，是一排排两米高的机柜，共40个，排成U字形，塞满了一个大房间。

```
┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐
│ 累加器1 │  │ 累加器2 │  │ 乘法器  │  │ 除法/  │
│        │  │        │  │        │  │ 开方器  │
└────────┘  └────────┘  └────────┘  └────────┘
┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐
│ 函数表  │  │ 常数   │  │ 主程序  │  │ 启动   │
│        │  │ 发送器  │  │ 控制器  │  │ 单元   │
└────────┘  └────────┘  └────────┘  └────────┘
         ... 共40个机柜，排成U字形 ...
```

每个机柜内部密密麻麻排满了真空管、电阻、电容、继电器。编程方式是用插拔电缆和转动开关——每一次修改程序，需要物理上重新连接几百根线。

### ENIAC的"内存"

ENIAC没有我们现在理解的"内存"（RAM）。它的数据存储在20个"累加器"里，每个累加器能存一个10位十进制数。总共能存20个数字。

**20个数字。** 你手机内存是8GB，可以存大约20亿个数字。

### ENIAC用来干什么

不是打游戏，不是上网——是给美国陆军计算弹道表。一门炮从A点打到B点，需要知道仰角多少度才能命中。这涉及复杂的微分方程，以前全靠人工计算（"Computer"在1940年代指的是人——专门做计算的女性数学家），算一条弹道需要20小时，ENIAC用30秒。

## 二、为什么非得用真空管——1946年没有别的选择

### 真空管是什么

真空管是一个玻璃灯泡（跟老式灯泡差不多），里面抽成真空，有灯丝、栅极、阳极三个电极。它的工作原理简单来说是：

```
灯丝加热 → 发射电子 → 栅极控制电子流量 → 阳级收集电子
（类似一个水龙头：栅极是开关，控制电子这个"水流"的大小）
```

真空管能做两件事：
1. **放大信号**（一个小电压控制大电流）——这是收音机、电视机的核心
2. **做开关**（开/关两种状态）——这是计算机二进制的基础

### 真空管作为计算机元件的致命缺陷

**缺陷1：大。** 一根真空管约拳头大小。ENIAC用了18000根。

**缺陷2：耗电。** 每根真空管灯丝需要加热（就像白炽灯泡），18000根一直亮着，耗电150千瓦。

**缺陷3：发热。** 18000个微型电热器挤在一起，ENIAC运行时室温高达50°C，必须有专用冷却系统。

**缺陷4：短命。** 真空管像灯泡一样会烧。ENIAC每两天就烧一根，维护团队的主要工作就是找到烧掉的那根然后换掉。

**缺陷5：慢。** 真空管的开关速度是毫秒级的（千分之一秒），一个计算周期需要几毫秒。

**但1946年没有别的选择。** 晶体管在第二年（1947年）才被发明。

## 三、第一次跃迁：晶体管（1947）——从拳头变成米粒

### 发明的戏剧性——不只是技术，也是一场恩怨

1947年12月23日，贝尔实验室的巴丁（理论物理学家）、布拉顿（实验物理学家）、肖克利（团队领导）三人用一片锗晶体、两条金线、一块金属底座，搭出了世界上第一个晶体管。它大概一瓶盖大小。

但故事远不止技术突破。

肖克利对团队极度保密——巴丁和布拉顿做实验的时候，肖克利不允许其他同事进入实验室。当晶体管被证明可行后，肖克利试图把专利只写自己名字，巴丁和布拉顿发现后大闹贝尔实验室管理层，最终三人共享了专利和1956年的诺贝尔物理学奖。

更戏剧性的是后面：肖克利离开贝尔实验室，在硅谷创建了肖克利半导体实验室，招募了八个最顶尖的年轻科学家。但他是个糟糕的管理者——偏执、多疑、动不动用测谎仪测试员工。一年内，这八个人集体辞职。

这八个人后来被称为"八叛逆"（Traitorous Eight）——他们创立的仙童半导体（Fairchild Semiconductor）成为硅谷的黄埔军校。仙童后来又衍生出Intel、AMD、National Semiconductor等几十家芯片公司。

**某种意义上，整个硅谷都是肖克利把最优秀的人逼走的结果。**

### 晶体管VS真空管：不是一个量级

| 特性 | 真空管 | 晶体管（1950年代） | 优势倍数 |
|------|--------|------------------|---------|
| 大小 | 拳头大 | 米粒大 | ~100倍 |
| 耗电 | 几瓦 | 几毫瓦 | ~1000倍 |
| 发热 | 烫手 | 几乎不发热 | - |
| 寿命 | 几千小时 | 几十年 | ~100倍 |
| 开关速度 | 毫秒 | 微秒（百万分之一秒） | ~1000倍 |
| 可靠性 | 经常烧 | 极少坏 | ~100倍 |
| 成本 | 几美元 | 几美分 | ~100倍 |

### 第一个晶体管计算机

1954年，贝尔实验室造出了第一台晶体管计算机TRADIC（不是通用计算机，是给空军用的），用了800个晶体管，占地约一个冰箱大小，功耗不到100瓦——**比ENIAC小100倍，省电1500倍。**

但这只是开始。真正的革命发生在下一步。

## 四、第二次跃迁：集成电路（1958）——把整个电路印在一张硅片上

### "数字暴政"问题

晶体管虽然小，但制造计算机仍然需要**手工焊接**每个晶体管到电路板上。1960年代，一台高级计算机需要几十万个晶体管——如果所有连接都要人手工焊，这是物理上不可行的。

工程师管这个问题叫"数字暴政"（Tyranny of Numbers）——**你可以造出越来越小的元件，但你没法焊接越来越密的连线。**

### 两个人在同一年给出了同一个答案——然后打了十年专利官司

1958年，德州仪器公司的杰克·基尔比（Jack Kilby）做了一个天才设计：**不单独制造晶体管然后焊接，而是在同一片半导体材料上同时制造出晶体管、电阻、电容和它们之间的连线。** 他搭出了世界上第一块集成电路，一块锗片上集成了一个晶体管和几个电阻电容。2000年他因此获得诺贝尔物理学奖。

但基尔比的方案有个致命问题：各个元件之间用细金线手工连接——本质上还是"焊接"，只是焊得小。

同年，一个叫罗伯特·诺伊斯（Robert Noyce，后来Intel的创始人）在仙童半导体独立发明了另一个方案：用硅代替锗，用光刻技术把金属导线"印"在硅片表面——不需要手工接线。诺伊斯的方法才是今天所有芯片的基础。

接下来发生的是科技史上最著名的专利战之一：德州仪器和仙童半导体打了十年官司，双方都声称自己发明了集成电路。最终法院裁定：基尔比是"第一个做出来的人"，诺伊斯是"第一个做出可大规模生产方案的人"——两人共享荣誉。

诺伊斯后来和戈登·摩尔一起创立了Intel。基尔比在德州仪器继续工作了半辈子。两人至死没有成为朋友，但他们各自的工作加在一起，才让芯片从实验品变成了商品。

### 集成电路意味着什么

```
1960年：一块芯片上约10个晶体管
1965年：一块芯片上约64个晶体管（Intel第一款产品）
1971年：Intel 4004，世界第一颗微处理器，2300个晶体管，一颗指甲盖大小
1974年：Intel 8080，6000个晶体管，Altair 8800（第一台个人电脑的核心）
```

从18000根真空管（1946，一间房）→ 2300个晶体管（1971，指甲盖）——同等的计算能力，体积缩小了100万倍。

## 五、第三次跃迁：摩尔定律（1965-至今）——每两年翻一番，持续了60年

### 戈登·摩尔的一张图

1965年，英特尔联合创始人戈登·摩尔在《电子学》杂志上画了一张图，显示集成电路上的晶体管数量每年翻一番。他预测这个趋势会持续。他后来把预测调整为每两年翻一番。

**这个预测持续了将近60年。**

### 晶体管数量的指数增长

| 年份 | 处理器 | 晶体管数 | 相比ENIAC |
|------|--------|---------|-----------|
| 1946 | ENIAC | 18,000（真空管） | 1× |
| 1971 | Intel 4004 | 2,300 | 0.13× |
| 1978 | Intel 8086 | 29,000 | 1.6× |
| 1989 | Intel 80486 | 1,200,000 | 67× |
| 2000 | Pentium 4 | 42,000,000 | 2,333× |
| 2010 | Core i7 | 1,170,000,000 | 65,000× |
| 2022 | Apple M1 Ultra | 114,000,000,000 | 6,333,333× |
| 2025 | 英伟达 B200 | 208,000,000,000 | 11,555,555× |

1989年到2025年，36年，晶体管数量增加了17万倍。**人类历史上没有任何其他技术指标以这个速度增长过。不是汽车、不是飞机、不是火箭——全都没有。**

### 为什么能做到：光刻技术的持续突破

制造芯片就像在指甲盖上雕刻一座城市——只是你雕的不是建筑，是晶体管。

```
光刻技术原理（极简版）：
1. 涂：在硅片上涂一层光刻胶（对光敏感的材料）
2. 照：用极紫外光透过"掩膜"（电路设计图）照射硅片
3. 刻：照到光的光刻胶溶解，露出下面的硅
4. 蚀：用化学/等离子体刻蚀露出的部分
5. 洗：清除剩余光刻胶
6. 重复上述流程50-80次 → 芯片上就有了几百亿个晶体管

关键进化：光的波长越短，能刻出的线条越细
1980年代 → 紫外光（365nm）→ 线条宽度：1微米
2000年代 → 深紫外（193nm）→ 线条宽度：90纳米
2020年代 → 极紫外（13.5nm）→ 线条宽度：3纳米
```

3纳米是什么概念？一根头发的直径是80000纳米。**3纳米，大概是一根头发的二万六千分之一。** 台积电和三星就是在这种尺度上"雕刻"出几百亿个晶体管的。

## 六、从ENIAC到iPhone：一个数字对比告诉你发生了什么

把ENIAC时代和2026年放在一张表上：

| 指标 | ENIAC (1946) | iPhone 16 (2026) | 差距 |
|------|-------------|-------------------|------|
| 重量 | 30吨 | 200克 | 15万倍 |
| 体积 | 170平米 | 手掌大小 | ~100万倍 |
| 功耗 | 150千瓦 | 充一次电用一天(约5瓦) | 3万倍 |
| 算力 | 5000次/秒 | ~20万亿次/秒（NPU） | 40亿倍 |
| 内存 | 20个数字 | 8GB（约20亿个数字） | 1亿倍 |
| 存储 | 无（程序靠接线） | 256GB | 无→有 |
| 造价 | $500,000(1946年，约$700万现价) | ¥6000 | ~1000倍 |
| 可靠性 | 2天烧一根管子 | 故障率<0.001%/年 | >100万倍 |
| 编程 | 重新接线（几小时到几天） | 触屏下载App（几秒） | - |

**80年，算力提升40亿倍，体积缩小100万倍，成本降到千分之一。**

这背后是三件事：
1. 晶体管（1947）→ 把开关元件缩小100倍
2. 集成电路（1958）→ 把整个电路印到一片硅上
3. 摩尔定律驱动的持续60年光刻技术进步 → 每两年把晶体管数量翻一番

**还有一个隐藏的第四件事**：硅。地球上最丰富的元素之一（沙子的主要成分就是二氧化硅）。如果计算机需要用黄金或铂金来制造，它永远不会普及。但硅——地球上到处都是——这让芯片可以以数美元的价格大规模生产。

---

> 💡 **总结**：第一台电脑之所以是庞然大物，不是因为它"太原始"，而是因为1946年人类的物理技术只能造出真空管。从真空管到晶体管到集成电路到3纳米光刻，这80年的技术进步速度超过了人类历史上任何其他领域——你要感谢的不只是摩尔，还有整个半导体产业几十万工程师的持续工作。
