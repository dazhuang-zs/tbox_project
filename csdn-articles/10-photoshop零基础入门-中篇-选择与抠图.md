## 开篇：选区和抠图的关系——先理解这个

我第一次帮人抠图的时候，用橡皮擦硬擦了一个小时，结果边缘像狗啃的一样。对方看了一眼说："你用的橡皮擦吧？"——当场社死。

后来才知道，PS抠图的正道是**选区，不是橡皮擦**。

**选区**：你用工具圈出来的一块区域（屏幕上出现蚂蚁线虚线）。选区内的东西可以被编辑、复制、删除；选区外的不受影响。

**抠图**：创建选区 → 把选区内的内容单独提取出来 → 换上新背景。

> 💡 抠图的核心不是"怎么操作工具"，而是"怎么做出完美的选区"。工具只是手段，选区才是目的。

一个完整的抠图流程：

```
打开图片 → 选择抠图工具 → 创建选区 → 调整选区边缘 → 
按Ctrl+J把选区内容复制到新图层 → 隐藏原图层 → 看到透明背景 → 完成
```

## 第一章：选框工具（矩形 + 椭圆）——规则形状的王牌

**适用场景**：裁圆形头像、扣规则形状的按钮/图标/logo

**快捷键：M**

### 1.1 矩形选框工具

```
基础操作：
1. 选工具栏的矩形选框工具（M）
2. 在画布上按住鼠标拖 → 拉出一个矩形虚线框
3. 松手 → 矩形区域被选中
4. Ctrl+J → 选中区域复制到新图层

配合按键：
- 按住Shift拖 → 正方形（不是矩形）
- 按住Alt拖 → 从中心开始画（不是从角开始）
- Shift+Alt拖 → 从中心画正方形
```

### 1.2 椭圆选框工具

操作方法同上，只是拉出来是椭圆。

```
- 按住Shift拖 → 正圆形
- 按住Alt拖 → 从中心画椭圆
- Shift+Alt拖 → 从中心画正圆
```

### 1.3 选区的加减（所有选择工具通用）

在画选区时或已经画好后：

| 操作 | 按键 | 鼠标旁边出现的符号 |
|------|------|------------------|
| 新建选区 | 不按任何键 | ＋ |
| 加到选区 | 按住 **Shift** | ＋＋ |
| 从选区减去 | 按住 **Alt** | ＋− |
| 选区交叉 | 按住 **Shift+Alt** | ＋× |

```
实用例子：想选中一个甜甜圈形状（圆环）
→ 先画个大圆 → 按住Alt再画个小圆在里面 → 大圆减去小圆 = 圆环
```

### 1.4 羽化——让边缘柔和过渡

在选框工具的选项栏里有一个"羽化"参数：

```
羽化 = 0px → 边缘锋利（适合抠产品图）
羽化 = 5px → 边缘轻微模糊（适合抠人物）
羽化 = 20px → 边缘柔和过渡（适合做光晕、背景融合）
```

> 设置羽化 **必须在画选区之前**！画完再设没效果。画完想加羽化：菜单 → 选择 → 修改 → 羽化。

## 第二章：套索工具——自由形状的救星

**适用场景**：不规则但边缘清晰的主体、需要手动控制的抠图

**快捷键：L**

### 2.1 套索工具（自由画线）

```
操作：
按住鼠标左键，像用铅笔画画一样围绕主体画一圈。
松手后起点和终点自动闭合。

缺点：手抖就画歪了。适合对精度要求不高的情况。
```

### 2.2 多边形套索工具（直来直去）

**最实用的手动抠图工具之一**。

```
操作：点一下 → 一个锚点 → 移到下一个位置再点一下 → 又一个锚点。
     两点之间自动连成直线。一圈点完回到起点 → 双击闭合。

适合：扣棱角分明的物体（建筑、纸箱、手机、盒子）
不适合：曲线边缘（人脸、花瓣）
```

**实战技巧**：
- 点错了 → 按Delete删除上一个锚点
- 放大画布（Ctrl++）再点，精度高很多
- 锚点越密，边缘越精细
- 直线边缘只需要点两个端点

### 2.3 磁性套索工具（自动吸附边缘）

```
操作：
1. 在主体边缘点一下（起点）
2. 沿着边缘慢慢移动鼠标（不用按住！）
3. PS会自动在边缘上添加锚点（像磁铁吸住边缘）
4. 回到起点附近 → 点一下闭合

自动吸附条件：
- 主体和背景必须有明显的颜色/亮度差异
- 差异越大，吸得越准
- 差异小的地方需要手动点锚点
```

> 💡 磁性套索的实用场景：扣白底上的深色物体（效果很好）、扣复杂背景上的主体（效果一般，不如快速选择）。

## 第三章：快速选择工具 + 魔棒——智能选择的时代

**快捷键：W**

这两个工具在同一个按钮位置，长按切换。

### 3.1 快速选择工具（涂抹式选择）

**目前最常用的自动选择工具，适合大多数场景。**

```
操作：
1. 选快速选择工具（W）
2. 在选项栏调整画笔大小（[ ]键调节）
3. 像用画笔一样在主体上涂抹
4. PS自动识别边缘，把相似区域一起选中
5. 选多了 → 按住Alt + 涂选多的区域（减去）
6. 选少了 → 继续涂没选中的区域（添加）
```

**关键参数（选项栏）：**

| 参数 | 建议值 | 作用 |
|------|--------|------|
| 画笔大小 | 根据主体调整 | 大块区域用大笔刷，边缘用小笔刷 |
| 硬度 | 100% | 选边缘锐利 |
| 对所有图层取样 | 不勾选 | 只在当前图层上选 |
| 自动增强 | 勾选 | 自动优化边缘 |

**适合快速选择的图**：主体和背景颜色差异明显、主体边缘清晰
**不适合的图**：主体和背景颜色相近、毛发很多的人/动物、半透明物体

### 3.2 魔棒工具（点一下选相同颜色）

```
操作：
1. 选魔棒工具（长按快速选择切换）
2. 在背景上点一下 → PS选中所有相似颜色的区域
3. 按住Shift → 点其他没选中的背景 → 加到选区
4. 选完背景后 → 菜单 → 选择 → 反选（Ctrl+Shift+I）→ 主体被选中了
```

**关键参数（选项栏的"容差"）**：

```
容差 = 10 → 只选和点击点几乎一样的颜色
容差 = 32 → 默认值，选相近的颜色
容差 = 100 → 选范围很大，连不相关的颜色都可能选到

经验值：
- 纯色背景抠图：容差 10-20
- 渐变背景抠图：容差 30-50
- 复杂背景：魔棒不适合，用快速选择
```

**选项栏几个按钮的区别：**

```
┌─────────────────────────────────┐
│ □  新选区  │ 每次点击创建新选区    │
│ □□ 添加到  │ 每次点击加到已有选区   │
│ □− 减去    │ 每次点击从选区删除     │
│ □× 交叉    │ 只保留两次选区的交集    │
└─────────────────────────────────┘
```

## 第四章：选择并遮住（Select and Mask）——精细抠图的终极武器

**快捷键：选好粗略选区后 → 选项栏点"选择并遮住"按钮**

这是PS专门为处理**毛发、头发丝、羽毛、树木枝干**等精细边缘设计的。

### 4.1 工作流程

```
第1步：先用快速选择工具选一个大概的主体
      （不用完美，大概选上80%就行）

第2步：点击选项栏的"选择并遮住"按钮
       → 进入专门的工作界面

第3步：左侧工具栏变成：
       - 快速选择工具（继续加减选区）
       - 调整边缘画笔工具（⭐核心，处理头发边缘）
       - 画笔工具（手动涂）
       - 抓手/缩放

第4步：右侧面板调整参数：
       - 视图模式：选"叠加"或"黑底"看抠图效果
       - 透明度：调低可以看到原图
       - 半径：1-5px，边缘越复杂越大
       - 智能半径：勾选自动判断边缘
       - 平滑：1-5，减少锯齿
       - 羽化：0.5-2px，让边缘自然
       - 对比度：5-20%，让边缘更清晰
       - 移动边缘：-20%到+20%，收缩/扩展选区

第5步：用"调整边缘画笔"在头发边缘涂抹
       → PS自动把头发丝从背景中分离出来

第6步：输出设置 → 输出到：新建带有图层蒙版的图层 → 确定
```

### 4.2 实战：抠一个头发飘散的人像

```
全程操作：

1. 打开照片 → Ctrl+J 复制图层

2. 用快速选择工具选中人物主体（头发边缘不用太细）
   选多了按Alt减去，选少了继续涂

3. 点选项栏的"选择并遮住"

4. 视图模式改成"叠加"（红色半透明显示未选中区域）

5. 选"调整边缘画笔工具"（左侧第二个）
   画笔大小调到和头发宽度差不多

6. 沿着头发边缘涂抹 → PS自动计算哪些是头发哪些是背景
   注意：只涂头发边缘！不要把画笔涂到脸上或身体上

7. 检查效果：
   视图模式改成"黑底" → 看头发边缘有没有残留白色
   有残留 → 用调整边缘画笔再涂

8. 输出设置选"新建带有图层蒙版的图层" → 确定

9. 回到主界面 → 在图层面板底部新建一个纯色图层
   → 随便选个颜色看抠图效果 → 有没有锯齿、白边

10. 有不满意的地方 → 双击图层蒙版 → 用黑/白画笔微调
```

## 第五章：钢笔工具——终极精确（适合愿意花时间的人）

**快捷键：P**

钢笔工具是PS里学习曲线最陡但抠图精度最高的工具。适合需要完美边缘的商业项目。

### 5.1 钢笔工具的基本逻辑

```
钢笔不画"线"，画"路径"。

路径由"锚点"和"手柄"组成：

       手柄
        ↓
    ●──────●  ← 锚点
   /        \
  ●          ●
 /            \
●              ● ← 起始点

- 锚点：路径转折的地方
- 手柄：控制曲线的弯曲方向和弧度
```

### 5.2 基础操作

```
第1步：选钢笔工具（P）

第2步：在选项栏确认：
       模式选"路径"（不是"形状"！）

第3步：沿着主体边缘点击
       - 在直线上点：直接点下一个锚点，两点间是直线
       - 在曲线上点：点下去后不松手 → 拖动鼠标 → 拉出手柄调整曲线

第4步：三种锚点类型：
       - 角点：直接点，不拖（用于直角转折）→ 直线
       - 平滑点：点 + 拖出两个手柄 → 平滑曲线
       - 拐角点：点 + 拖 → 再按住Alt点一下锚点 → 折断手柄
                     （一边曲线一边直线）

第5步：辅助键：
       - Ctrl + 点锚点 → 拖动锚点位置
       - Ctrl + 点手柄 → 调整曲线弧度
       - Alt + 点锚点 → 删除一侧手柄
       - Delete → 删除上一个锚点
       - 点回起点 → 闭合路径

第6步：路径闭合后 → 右键 → 建立选区
       羽化半径：0.5-2px → 确定
       
第7步：Ctrl+J → 抠出主体
```

### 5.3 钢笔抠图实战：扣一个产品图（瓶子/杯子）

```
实战步骤（瓶子有直线和曲线，最适合练习）：

1. 选钢笔工具（P）

2. 把图放大到 200%（Ctrl++）

3. 从瓶盖顶部开始：
   - 点第一个锚点
   - 沿着直线部分 → 在拐角处点第二个锚点 → 直线自动生成
   - 到了瓶身曲线部分：
     → 点下去不松手 → 水平方向拉出手柄 → 调整到曲线贴合瓶身边缘
   - 继续循环：直线直接点，曲线点+拖

4. 整圈走完回到起点 → 光标旁出现小圆圈 → 点一下闭合

5. 如果有不贴合的地方：
   - 按住Ctrl → 点不贴合的锚点 → 拖动到正确位置
   - 按住Ctrl → 点手柄端点 → 拖动调整曲线弧度

6. 右键路径 → 建立选区 → 羽化1px → 确定

7. Ctrl+J 抠出瓶子
```

**钢笔工具练习法**：找简单的几何物体（杯子、手机、盒子）练10次，就会了。不要一上来就扣人脸。

## 第六章：5种抠图方法选择决策树

```
你要抠的图是什么样的？

├── 规则形状（圆形/方形/椭圆形）
│   → 选框工具（M）
│   例：圆形头像、方形logo
│
├── 不规则但边缘清晰，主体和背景颜色不同
│   → 快速选择工具（W）
│   例：白底产品图、蓝天前的建筑
│
├── 纯色背景
│   → 魔棒工具（W长按切换），选背景→反选
│   例：纯白/纯蓝背景的证件照
│
├── 棱角分明的物体
│   → 多边形套索（L长按切换）
│   例：盒子、手机、书本
│
├── 有毛发/羽毛/树枝等复杂边缘
│   → 快速选择+选择并遮住
│   例：人物照片、宠物照片
│
└── 需要完美边缘（商业级）
    → 钢笔工具（P）
    例：产品精修、UI切图、需要放大的图
```

## 第七章：抠图后常见问题处理

### 问题1：抠出来边缘有白边

```
原因：原图背景是白色或浅色的，抠图时带了半像素的白边

解决：
1. 按住Ctrl + 点抠出来的图层缩略图 → 创建选区
2. 菜单 → 选择 → 修改 → 收缩 → 1-2像素
3. Ctrl+Shift+I 反选
4. 按Delete删除白边
5. Ctrl+D 取消选区
```

### 问题2：抠出来的边缘太锋利/太生硬

```
解决：
1. 按住Ctrl + 点图层缩略图 → 创建选区
2. 菜单 → 选择 → 修改 → 羽化 → 1-2像素
3. Ctrl+Shift+I 反选
4. 按Delete（一次不够可以多按两次）
```

### 问题3：抠出来的主体边缘带了原背景的颜色

```
解决：
1. 在抠出来的图层上 → 新建一个空白图层 → 右键"创建剪贴蒙版"
2. 用吸管工具取主体旁边的颜色
3. 用画笔在边缘涂抹中和掉杂色
4. 图层不透明度降到 50%
```

### 问题4：抠图完成后，放到新背景上颜色不协调

```
原因：原图光线环境和新背景不一样

解决：
1. 选中抠出来的图层
2. 菜单 → 图像 → 调整 → 匹配颜色（将主体色调向背景靠拢）
或
1. 新建调整图层（亮度/对比度、色彩平衡）
2. 右键调整图层 → 创建剪贴蒙版（只影响抠出来的图层）
```
