## 二、先认5个东西（其他的暂时不用管）

打开PS/Photopea后，你只需要认识这5个：

```
┌─────────────────────────────────────────────┐
│  菜单栏  [文件] [编辑] [图像] [图层] ...      │ ← 偶尔用
├──────────┬──────────────────────────────────┤
│          │                                  │
│  工具栏   │         画布区域                  │
│  ┌──┐    │                                  │
│  │移│    │      （你的图片在这里编辑）          │
│  ├──┤    │                                  │
│  │选│    │                                  │
│  ├──┤    │                                  │
│  │裁│    │                                  │
│  ├──┤    │                                  │
│  │T │    │                                  │
│  └──┘    │                                  │
├──────────┴──────────────────────────────────┤
│  底部状态栏                   50% | 图层可见  │
└─────────────────────────────────────────────┘
         右侧面板
     ┌──────────────┐
     │   颜色面板    │
     ├──────────────┤
     │   图层面板    │
     │  ┌─图层2     │
     │  ├─图层1     │  ← 最重要的面板
     │  └─背景      │
     └──────────────┘
```

**5个必须知道的东西：**

| 序号 | 东西 | 在哪 | 干什么用 |
|------|------|------|---------|
| 1 | **移动工具** | 工具栏最上面那个箭头 | 拖动图片/文字/形状 |
| 2 | **图层面板** | 右下角 | 管理所有元素（核心！） |
| 3 | **文字工具** | 工具栏的 T 图标 | 添加文字 |
| 4 | **裁剪工具** | 工具栏第5个 | 裁切图片大小 |
| 5 | **保存/导出** | 菜单栏 → 文件 | 导出成品 |

> ⚠️ 图层是PS最重要的概念。**每一个元素（图片、文字、形状）都在一个独立的"层"上，像叠透明玻璃板一样。** 修改上层不影响下层。

## 三、项目1：公众号封面图（10分钟）

**需求**：做一张 900×383 像素的公众号封面，放标题文字 + 一张背景图。

### 第1步：新建画布

```
菜单栏 → 文件 → 新建
宽度：900 像素
高度：383 像素
背景内容：白色
→ 点"创建"
```

### 第2步：添加背景图

```
菜单栏 → 文件 → 打开并置入...
→ 选择你的背景图片
→ 图片会出现在画布中央，四周有小方块（控制点）
→ 拖动四角的控制点调整大小（按住Shift保持比例）
→ 按 Enter 确认
```

### 第3步：让背景变暗（让文字更清晰）

```
1. 在图层面板选中背景图层
2. 点击图层面板底部的"创建新填充或调整图层"按钮（半黑半白的圆）
3. 选择"亮度/对比度"
4. 降低"亮度"到 -30 左右
```

### 第4步：添加标题文字

```
1. 选择工具栏的 T 文字工具
2. 在画布中间点击，输入标题文字
3. 顶部会出现文字选项栏：
   - 字体：选一个粗的（如"思源黑体 Bold"）
   - 字号：48pt 左右
   - 颜色：白色
4. 用移动工具把文字拖到中间位置
```

### 第5步：导出

```
菜单栏 → 文件 → 导出为 → PNG
→ 点"保存"
```

**你的第一张PS作品完成了。**

## 四、项目2：证件照换底色（15分钟）

**需求**：把蓝底证件照换成红底/白底。

这是Photoshop最实用的技能之一——省去照相馆50块钱。

### 方法：用"快速选择工具" + "蒙版"

```
第1步：打开照片
文件 → 打开 → 选择你的证件照

第2步：复制图层（好习惯，不破坏原图）
在图层面板中，右键"背景"图层 → 复制图层

第3步：选中人物
1. 选择工具栏的"快速选择工具"（从上往下数第4个，图标像魔术棒+圆圈）
2. 在人物身上点击并拖动，PS会自动识别边缘
3. 选多了？按住Alt键 + 点击多出来的区域（减去选区）
4. 选少了？继续点击没选中的区域
5. 直到人物被虚线完全包围

第4步：去掉背景（关键一步）
在选区内右键 → 选择"通过拷贝的图层"（Ctrl+J）
→ 图层面板中会出现一个新图层，只有人物，没有背景

第5步：换成新底色
1. 点击图层面板底部的"创建新图层"按钮（折角纸的图标）
2. 把新图层拖到"人物图层"下方
3. 选择你想要的背景色：工具栏底部有两个色块 → 点下面的色块 → 选红色/白色
4. 菜单栏 → 编辑 → 填充 → 前景色 → 确定

第6步：导出
文件 → 导出为 → JPEG（选最高质量）
```

**常见问题**：
- 头发边缘有蓝色残留 → 用"橡皮擦工具"，画笔大小调到20px，硬度降到0%，轻轻擦拭边缘
- 选多了背景 → 选多了就按Ctrl+Z撤销，重新用Alt+点击减去
- 边缘太生硬 → 选区 → 选择并遮住 → 羽化1-2像素

> 💡 **专业提示**：如果头发丝比较碎（女生散发），快速选择工具可能选不好。这时候用"选择 → 主体"（PS 2021+），AI自动抠人效果很好。

## 五、项目3：产品图美化（20分钟）

**需求**：给一张拍摄的产品照片做基础美化——调亮、去瑕疵、加倒影。

### 第1步：自动调色（10秒搞定）

```
菜单栏 → 图像 → 自动色调   (Ctrl+Shift+L)
菜单栏 → 图像 → 自动对比度 (Ctrl+Alt+Shift+L)
菜单栏 → 图像 → 自动颜色   (Ctrl+Shift+B)

三个自动一般能解决80%的曝光和色偏问题。
```

### 第2步：手动微调（如果自动效果不理想）

```
图层面板底部 → "创建新的填充或调整图层" → 选择"色阶"

会出现一个图表（直方图）：
- 左边黑色三角 → 向右拖（让暗部更暗）
- 右边白色三角 → 向左拖（让亮部更亮）
- 中间灰色三角 → 向左拖变亮，向右拖变暗

一般把黑白三角拖到直方图"有数据"的位置即可。
```

### 第3步：去水印/去瑕疵

```
1. 选择"污点修复画笔工具"（工具栏第7个，创可贴图标）
2. 在顶部选项栏调整画笔大小（比你要去除的瑕疵稍大一点）
3. 直接在瑕疵上点击 → PS自动用周围纹理填补
4. 一条线的水印？按住鼠标沿着线拖动即可
```

> ⚠️ 注意：如果水印覆盖在复杂纹理上（如衣服花纹），这个方法效果不好。大面积水印需要用"内容识别填充"：套索工具圈中水印区域 → 右键 → 填充 → 内容识别 → 确定。

### 第4步：加倒影（让产品图高级感+100%）

```
1. 在图层面板中，右键产品图层 → 复制图层
2. 选中复制出来的图层
3. 菜单栏 → 编辑 → 变换 → 垂直翻转
4. 用移动工具把翻转后的图层拖到原产品下方
5. 在图层面板中，把翻转图层的"不透明度"调到 30%
6. 用"渐变工具"+ 图层蒙版让倒影渐淡（进阶操作，可选）
```

## 六、项目4：一张简单的活动海报（25分钟）

**需求**：做一张 800×1200 的竖版活动海报，含背景、标题、时间、地点、二维码。

### 第1步：创建画布 + 背景

```
文件 → 新建
宽度：800px，高度：1200px
背景内容：白色

找个背景：
- 方案A：用纯色背景 → 新建图层 → 编辑 → 填充 → 选一个深色
- 方案B：用渐变 → 工具栏选"渐变工具" → 顶部选一个预设渐变 → 从画布顶部拖到底部
```

### 第2步：添加主标题

```
1. T 文字工具 → 在画布上1/3处点击
2. 输入标题文字（如"2026技术分享大会"）
3. 选中文字 → 顶部选项栏调整：
   - 字体：粗体（思源黑体 Bold 或 庞门正道标题体）
   - 字号：72pt
   - 颜色：白色或亮色
   - 对齐：居中对齐
4. 移动工具调整位置
```

### 第3步：添加时间和地点

```
1. T 文字工具 → 在标题下方点击
2. 输入"时间：2026年6月15日 14:00"
3. 字号：36pt，颜色：浅色
4. 换行，输入"地点：线上直播"
5. 用移动工具把时间地点拖到画布中间

💡 排版技巧：
- 标题大（72pt）→ 时间地点中（36pt）→ 形成层次感
- 不同内容之间用空行隔开
- 文字居中对齐最安全
```

### 第4步：加装饰元素

```
方法1：加一条分隔线
1. 选择"矩形工具"（工具栏的方框图标）
2. 在标题和时间之间画一个细长矩形
3. 在图层面板中把矩形的不透明度调到 50%
4. 用移动工具居中对齐

方法2：加一个半透明色块衬托文字
1. 矩形工具 → 在文字区域画一个矩形
2. 图层面板中把矩形图层拖到文字图层下方
3. 调低矩形的不透明度到 30%
4. 填充颜色选黑色或主题色
```

### 第5步：导出

```
文件 → 导出为 → PNG

如果是印刷：导出为 PDF（保留矢量文字清晰度）
如果是手机传播：800×1200 正好是 2:3 比例
```

## 八、做图的通用法则（学会了任何工具都能用）

### 排版三原则
1. **对齐**：所有元素对齐到一条线，不要东一个西一个
2. **层次**：最重要的最大/最粗/最亮；次要的小/细/暗
3. **呼吸**：文字四周留白，不要贴边

### 配色三公式
1. **黑白金**：深色背景 + 白色文字 + 金色强调（永远不会错）
2. **单色系**：一个颜色 + 不同深浅（保守但干净）
3. **互补色**：蓝+橙、紫+黄（活泼但要克制，只用一种做主色）

### 字体三规则
1. 一张图最多用2种字体（一种标题+一种正文）
2. 正文不要用花体/手写体（看不清）
3. 中文标题推荐：思源黑体 Bold、庞门正道标题体
