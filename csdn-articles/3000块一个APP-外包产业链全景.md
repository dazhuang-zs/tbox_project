<a name="一"></a>
## 一、一条朋友圈里的价格魔术

先看两个真实的报价（来自公开接单平台和社区分享）：

> "某教育机构需要一个在线课程系统，包括视频播放、作业提交、在线考试，预算5万。"

> 同一个需求，在另一个群里："课程系统开发，预算8000，两周交付。"

同一个项目，价格差了6倍。为什么？

因为5万的那条，是终端客户直接发的。8000的那条，已经过了至少两道手。

<a name="二"></a>
## 二、产业链的四层解剖

程序员外包市场不是"甲方 → 程序员"这么简单。它是一条经过了多年自发演化、极度精细的分工链条：

```
终端客户（有需求、有预算）
    │
    ▼
┌─────────────────────┐
│ 第一层：项目代理商   │  正规外包公司 / 有客户资源的个人
│ 抽成：30%-50%        │  签合同、谈需求、收全款
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 第二层：二包 / 拆单  │  把大项目拆成小模块
│ 抽成：20%-30%        │  找下一层的人来做
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 第三层：接单平台     │  猪八戒、码市、程序员客栈……
│ 抽成：10%-20%        │  做信息撮合，收服务费
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 第四层：写代码的人   │  就是你
│ 到手：原价的15%-30%  │  承担全部执行风险和返工成本
└─────────────────────┘
```

> **💡 一个终端报价5万的项目，如果流到第四层，写代码的人拿到手的可能只有8000-15000。中间的差价不是"被坑了"，是产业链的运行成本——只不过这个成本，由最底层的执行者承担。**

<a name="三"></a>
## 三、每一层在做什么、赚多少

### 第一层：项目代理商

**谁在干**：正规外包公司、有稳定客户资源的自由职业者、行业里的"老炮儿"。

**他们提供什么价值**：
- 客户关系：终端客户信任他们，愿意把项目交给他们
- 商务能力：会谈价格、签合同、处理法律事务
- 项目管理：管控进度、协调资源、承担交付风险

**他们赚的是什么钱**：客户信任溢价 + 商务能力溢价 + 风险承担溢价。

这一层的人，大部分不懂技术细节。但他们懂客户、懂商务、懂怎么让人放心地把项目交给自己。**这些能力在程序员圈子里极度稀缺。**

### 第二层：二包 / 拆单人

**谁在干**：第一层的"下游合作方"，或者有一定技术背景的中间人。

**他们提供什么价值**：把一个复杂的大项目拆成可执行的小模块，分发给不同的人做，最后组装起来。类似于建筑行业的总包→分包模式。

**他们赚的是什么钱**：项目拆解和组织能力。这一层的人通常有点技术背景（至少能看懂需求、评估工时），但不一定亲自写代码。

### 第三层：接单平台

**谁在干**：猪八戒、码市、程序员客栈、以及各种"私活群""外包群"的群主。

**他们提供什么价值**：信息撮合。让甲方能找到程序员，程序员能找到甲方。

**他们赚的是什么钱**：信息差的钱。平台的模式是抽佣（10%-20%），群主可能收会员费或信息费。

### 第四层：写代码的你

你承担了：
- 全部的技术执行工作
- 需求理解偏差的风险
- 甲方需求变更的风险
- 项目烂尾的风险
- 售后维护的无限责任

你得到的是：**原报价的15%-30%。**

> **产业链的利润分配是反过来的：风险越大的人，分到的越少。**

<a name="四"></a>
## 四、你在第几层

大多数在群里蹲单的程序员，处于第三层和第四层之间。你在平台或群里抢单，平台抽一道；偶尔单子是从"二包"手里流下来的，又被抽了一道。

你可能会想：我只是想安安静静写代码赚钱，为什么这么难？

**因为"安安静静写代码"是一个在产业链最底层的定位。** 越往上走，你需要的非技术能力越多——但也越不可替代、利润越高。

看看这个对比：

| 你在第几层 | 主要能力 | 收入倍数（相对第四层） |
|:--|:--|:--|
| 第四层（纯写代码） | 技术 | 1x |
| 第三层（平台+写代码） | 技术 + 自我推广 | 1.5x |
| 第二层（接单+拆单+写代码） | 技术 + 商务 + 管理 | 3x-5x |
| 第一层（直接对终端客户） | 商务 + 品牌 + 客户关系 + 技术 | 5x-20x |

<a name="五"></a>
## 五、怎么往上走

看完这张图，你可能想说："但我就是不会谈客户、不会做商务。"

**这就是关键问题。如果你永远停留在"我就是不会"这个阶段，你就永远待在第四层。**

往上走不需要一夜之间变成销售专家。循序渐进：

**第一步：先摆脱对群和平台的依赖。**

哪怕只找到一个直接客户——通过前同事、朋友介绍、你自己写的文章吸引来的——你的收入立刻翻倍。因为省掉了中间两层的抽成。

**第二步：学习最基础的商务技能。**

会写报价单、会签合同、会跟客户说"这个做不了"——这些不是天赋，是可以学的技能。网上有模板，有教程，花一个下午就够了。

**第三步：建立你的垂直口碑。**

不要什么项目都接。选一个细分领域深耕，让客户在想到"做XX系统"的时候第一个想到你。

> **💡 编程让你的时间值钱。但商务能力让你的时间值更多钱。前者你已经练了十年。后者你还没开始。**

## 写在最后

这篇文章画了一张产业链全景图。目的不是让你愤怒——"原来我被抽了这么多"——而是让你看清自己的位置，然后决定：是继续在这个位置上卷价格，还是开始往上游移动。

产业链不会因为你更努力地写代码就改变。但你可以改变自己在产业链上的位置。
