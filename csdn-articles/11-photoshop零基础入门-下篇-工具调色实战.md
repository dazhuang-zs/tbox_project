## 第一章：五大核心工具详解

### 1.1 画笔工具（B）——PS里最灵活的工具

画笔不只是"画画的笔"。在PS里，画笔可以：
- 画颜色 → 在新图层上涂鸦
- 做蒙版 → 配合图层蒙版做局部调整
- 加光影 → 用白色/黑色画笔做高光/阴影
- 修瑕疵 → 配合修复工具

**基础操作：**

```
1. 选画笔工具（B）
2. 在画布上右键 → 弹出画笔预设面板：
   ┌──────────────────────┐
   │ 大小：  50 px        │ ← [ ] 键或拖动滑块调整
   │ 硬度：  0%  ←→ 100%  │ ← 0%边缘柔和(雾状), 100%边缘锋利
   │                      │
   │ [各种笔刷预设缩略图]    │
   └──────────────────────┘
3. 前景色选颜色 → 按住鼠标涂

选项栏关键参数：
┌────────────────────────────────────────────┐
│ 笔刷 ▾  │ 模式:正常  │ 不透明度:100%  │ 流量:100% │
└────────────────────────────────────────────┘

不透明度：一笔的颜色浓度（100%=全力, 50%=半透明）
流量：   移动时的颜料输出速度（像水彩颜料管口的松紧）
```

**三种必会的画笔用法：**

**用法1：硬边画笔（修图、精准涂色）**
```
硬度 = 100%
适合：抠图后修边缘、给文字上色、画清晰形状
```

**用法2：柔边画笔（光影、烟雾、过渡）**
```
硬度 = 0%
适合：给产品图加高光和阴影、做光晕、蒙版局部调色
```

**用法3：自定义笔刷（特殊纹理）**
```
选项栏 → 笔刷预设 → 点齿轮图标 → 导入笔刷
网上有大量免费笔刷：水彩、烟雾、光效、粒子等
```

### 1.2 文字工具（T）——排版从这里开始

文字工具分两种模式：

**点文字**（单行，不会自动换行）：
```
选T工具 → 在画布上点一下 → 开始打字 → 一直往右延伸
适合：标题、短句
```

**段落文字**（框内自动换行）：
```
选T工具 → 在画布上按住鼠标拖出一个文字框 → 开始打字
→ 文字自动在框内换行
适合：正文、多行文字
```

**选项栏详解：**

```
┌─────────────────────────────────────────────────────┐
│ T  │ 字体 ▼ │ 字重 ▼ │ 字号 ▼ │ 平滑 ▼ │ ≡ ≡ ≡ │ 色 ■ │
└─────────────────────────────────────────────────────┘

字体：  推荐中文字体（思源黑体、微软雅黑、庞门正道标题体）
字重：  粗体(Bold)、常规(Regular)、细体(Light)
字号：  标题48-72pt，正文18-24pt，小字12-14pt
对齐：  左对齐、居中、右对齐
颜色：  点色块弹出取色器
```

**字符面板（窗口 → 字符）——完整的文字控制：**

```
┌─────────────────────┐
│ 字体        字重     │
│ ───────────────────│
│ 字号    行距(上下行距离)│ ← 行距一般字号的1.2-1.5倍
│ 字距    字偶距        │ ← 调整字母/字之间的间距
│ ───────────────────│
│ 垂直缩放  水平缩放    │ ← 拉扁或拉高文字（少用）
│ 基线偏移            │ ← 上标/下标效果
│ ───────────────────│
│ 颜色               │
│ T T T 粗 斜 全大写  │
└─────────────────────┘
```

**常见文字效果（图层面板底部 fx 按钮）：**
- 描边：给文字加外框
- 投影：文字下方出现阴影（立体感）
- 渐变叠加：文字颜色变成渐变色
- 外发光：文字周围发光

### 1.3 形状工具（U）——不只会画方块

长按矩形工具按钮，可以看到6种形状：

| 形状 | 快捷键 | 用途 |
|------|--------|------|
| 矩形 | U | 按钮、卡片、色块背景 |
| 圆角矩形 | U长按切换 | 圆角按钮、现代UI元素 |
| 椭圆 | U长按切换 | 圆形头像、标签、图标底 |
| 多边形 | U长按切换 | 三角形、六边形、星形 |
| 直线 | U长按切换 | 分隔线、箭头 |
| 自定义形状 | U长按切换 | PS内置的各种形状 |

**形状图层的特殊之处：**

```
形状图层是矢量图层（和文字图层一样），好处是：
- 放大缩小不失真（不管放多大边缘都是锋利的）
- 随时可以改颜色（双击图层缩略图 → 弹出取色器）
- 随时可以改形状（Ctrl+T 缩放不变形）
- 随时可以改圆角大小（属性面板中拖动圆角半径）

普通图层放大缩小会越来越模糊，形状图层不会。
```

**实用示例：做圆角矩形按钮**

```
1. 选圆角矩形工具
2. 在画布上拖出矩形
3. 属性面板中调整圆角半径（4个角可以独立调）
4. 双击图层缩略图改颜色
5. 选文字工具 → 在按钮上点一下 → 输入"点击查看"
6. 移动工具把文字居中
```

### 1.4 修复工具组（J）——去水印、去瑕疵、去路人

**污点修复画笔（点一下就去掉）**

```
适合：去除脸上的痘痘、照片上的灰尘、小水印

操作：
1. 选污点修复画笔（J）
2. 画笔大小调到比瑕疵稍大一点即可
3. 在瑕疵上点一下 → PS自动用周围纹理填补
4. 没了。就这么简单。
```

**修复画笔工具（先取样再修复）**

```
适合：去除大面积瑕疵、需要指定"用什么纹理填补"

操作：
1. 选修复画笔工具（长按污点修复切换）
2. 按住Alt → 在"好的皮肤/纹理"上点一下（取样）
3. 松手 → 在瑕疵上涂抹
4. PS把取样区域的纹理复制过来，并自动融合边缘颜色

和污点修复的区别：
- 污点修复：PS自动选纹理（可能选到不合适的地方）
- 修复画笔：你手动指定纹理来源（更可控）
```

**修补工具（圈一块补到另一块）**

```
适合：去除大面积的水印、路人、杂物

操作：
1. 选修补工具（长按修复画笔切换）
2. 像套索一样把要去掉的区域圈起来
3. 把圈好的选区拖动到"想用哪块纹理填补"的地方
4. 松手 → PS自动融合

例子：照片里有路人 → 圈中路人的区域 → 拖到旁边的空地 → 路人消失
```

**内容感知移动工具（移走物体）**

```
操作：
1. 选内容感知移动工具（长按修补工具切换）
2. 圈中要移走的东西
3. 拖到新位置
4. 原来的位置被自动填充，物体出现在新位置
```

### 1.5 渐变工具（G）——告别纯色背景

渐变工具能做从一种颜色平滑过渡到另一种颜色的效果。

**基础操作：**

```
1. 选渐变工具（G）
2. 选项栏点渐变条 → 弹出渐变编辑器
3. 选一个预设渐变（或自己编辑）
4. 在画布上从A点拖到B点 → 渐变生成

拖动方向：
- 从上往下拖 → 上面是渐变起点色，下面是终点色
- 从中心往外拖 → 径向渐变（像太阳光）
- 对角线拖 → 斜向渐变
```

**五种渐变样式（选项栏）：**

```
┌─────────────────────────────────────────┐
│ ▨ 线性  │ ▣ 径向  │ ▤ 角度  │ ▥ 对称  │ ▦ 菱形  │
└─────────────────────────────────────────┘

线性：直线方向渐变（最常用）
径向：从中心向四周（像聚光灯）
角度：绕着一个点旋转渐变
对称：从中间向两边
菱形：菱形扩散
```

**自制渐变：**

```
1. 点选项栏的渐变条 → 弹出编辑器
2. 底部渐变色条两端各有一个小方块（色标）
3. 双击色标 → 弹出取色器 → 选颜色
4. 在色条下方点击 → 添加新的色标
5. 色标中间的小菱形 → 拖动调整两种颜色的过渡位置
```

## 第二章：调色入门——让图片不再"灰蒙蒙"

### 2.1 自动调色（10秒解决80%的问题）

```
菜单栏 → 图像 → 自动色调    (Ctrl+Shift+L)
菜单栏 → 图像 → 自动对比度  (Ctrl+Alt+Shift+L)
菜单栏 → 图像 → 自动颜色    (Ctrl+Shift+B)

原理：PS分析你的图片，自动拉伸色阶范围，纠正色偏。
适用：曝光不足/过度、偏黄/偏蓝的照片
```

**注意**：在调整图层上用不了"自动"。自动只能直接在图层上执行。要做无损的：先Ctrl+J复制一层 → 在复制层上自动 → 不满意就删掉。

### 2.2 色阶（Levels）——精确控制暗部、亮部、中间调

**为什么色阶比亮度/对比度好用？**

亮度/对比度："整张图变亮30%"
色阶："暗部不变，只提高亮部20%，降低中间调10%"

**操作**：

```
方式一（推荐——无损）：图层面板底部 → ◐ → 色阶
方式二（有损）：菜单 → 图像 → 调整 → 色阶 (Ctrl+L)

弹出窗口长这样：

       ┌──────────────────────┐
       │    输入色阶           │
       │                      │
       │  ■      ▲       ■    │ ← 直方图(像素分布)
       │  │      │       │    │
       │  ▼      ▼       ▼    │
       │  0     1.00    255   │
       │ 黑色   灰色    白色   │ ← 三个滑块
       │                      │
       └──────────────────────┘

三个滑块（从左边到右边）：

■ 黑色滑块（暗部）：向右拖 → 暗部更暗
▲ 灰色滑块（中间调）：向左拖变亮，向右拖变暗（最重要！）
■ 白色滑块（亮部）：向左拖 → 亮部更亮

经验：把黑色和白色滑块分别移到直方图"有数据"的位置即可。
```

**实战：拯救一张发灰的照片**

```
问题：照片整体发灰，没有纯黑和纯白

原因：相机的曝光范围没有覆盖0-255的全部范围

解决：
1. 新建色阶调整图层
2. 黑色滑块向右拖 → 拖到直方图"有数据"的起始位置
3. 白色滑块向左拖 → 拖到直方图"有数据"的结束位置
4. 灰色滑块微调 → 调到你喜欢的亮度

结果：照片瞬间从"灰蒙蒙"变得"对比清晰"
```

### 2.3 色相/饱和度——改变颜色

```
图层面板底部 → ◐ → 色相/饱和度

┌──────────────────────────┐
│ 全图        ▼            │ ← 可以只调某一种颜色
│ ─────────────────────── │
│ 色相：    0              │ ← 改变颜色（红变蓝、绿变紫）
│ 饱和度：  0              │ ← 颜色鲜艳程度（右=更鲜艳，左=变灰）
│ 明度：    0              │ ← 亮度（一般不调这个）
└──────────────────────────┘

实用场景：
- 提高饱和度 +10 → 照片更鲜艳
- 降低饱和度 -100 → 变成黑白照片（比"黑白"命令自然）
- 全图改"红色"，色相+30 → 口红变成橘色
```

### 2.4 色彩平衡——修正色偏

```
图层面板底部 → ◐ → 色彩平衡

┌────────────────────────────────────┐
│ 阴影  │  中间调  │  高光             │ ← 分别调整暗部/中间调/亮部
├────────────────────────────────────┤
│ 青色 ←──────────→ 红色  │
│ 洋红 ←──────────→ 绿色  │
│ 黄色 ←──────────→ 蓝色  │
└────────────────────────────────────┘

实用场景：
- 照片偏黄（室内灯光）→ 黄色滑块往蓝色方向拖
- 照片偏蓝（阴天）→ 蓝色滑块往黄色方向拖
- 想要暖色调 → 加红、加黄
- 想要冷色调 → 加蓝、加青
```

## 第三章：5个实战项目——把学到的全部串起来

### 项目1：公众号封面图（复习：新建文件、文字、形状、导出）

```
难度：⭐ | 复习技能：新建文件、文字工具、形状工具、渐变、导出

需求：900×383px 公众号封面
      深蓝渐变背景 + 白色标题 + 装饰线条 + 作者名

步骤：
1. 文件 → 新建 → 900×383px, 72PPI, RGB
2. 选渐变工具(G) → 编辑渐变：深蓝(#1a3a5c) → 浅蓝(#3a7bd5)
   → 从上往下拖
3. 选文字工具(T) → 输入标题"2026年AI编程工具全面对比"
   → 字号48pt, 白色, 居中
4. 选形状工具(U) → 矩形 → 在标题下方画一条细线（高2px）
   → 填充白色 → 不透明度30%
5. 再选文字工具 → 输入"你的名字 | 2026-05"
   → 字号18pt, 浅蓝色, 右下角
6. 文件 → 导出 → 导出为 → PNG → 完成
```

### 项目2：证件照换底色（复习：快速选择、选择并遮住、填充）

```
难度：⭐⭐ | 复习技能：快速选择、选择并遮住、新建图层、填充

需求：把蓝色背景证件照换成红色背景

步骤：
1. 打开照片 → Ctrl+J 复制图层
2. 快速选择工具(W) → 涂选人物主体
3. 选项栏 → 选择并遮住
4. 用调整边缘画笔涂头发边缘 → 输出到"新建带有图层蒙版的图层"
5. 回到主界面 → 新建图层 → 拖到人物图层下方
6. 工具栏底部 → 点前景色 → 选红色 → 确定
7. 编辑 → 填充 → 前景色 → 确定
8. 检查人物边缘：有没有蓝色残留？有→ 选人物图层蒙版 → 黑画笔微调
9. 文件 → 导出为 → JPEG → 完成
```

### 项目3：产品图去水印 + 调亮（复习：修复工具、色阶）

```
难度：⭐⭐ | 复习技能：修复画笔、修补工具、色阶调整

需求：去除产品图上的水印，调亮图片，让产品更突出

步骤：
1. 打开产品图 → Ctrl+J 复制图层

2. 去水印（三种方法根据水印类型选）：
   - 水印在纯色区域 → 污点修复 → 点一下
   - 水印在纹理区域 → 修复画笔 → Alt取样 → 涂抹
   - 水印是一大块 → 修补工具 → 圈中 → 拖到干净区域

3. 调亮：
   图层面板底部 → ◐ → 色阶
   白色滑块向左拖（到直方图数据位置）
   灰色滑块微调（让产品细节可见）

4. 加点锐度：
   选中产品图层 → 滤镜 → 锐化 → USM锐化
   数量：50%, 半径：1px, 阈值：0

5. 导出 → JPEG → 完成
```

### 项目4：简单活动海报（复习：所有核心技能）

```
难度：⭐⭐⭐ | 复习技能：新建文件、渐变、形状、文字、图层管理

需求：800×1200px 竖版海报
      渐变背景 + 主标题 + 副标题 + 时间地点 + 装饰元素 + 底部二维码预留位

步骤：
1. 新建 → 800×1200px, 72PPI, RGB

2. 背景：
   渐变工具(G) → 编辑：深紫(#2d1b69) → 深蓝(#1a3a5c) → 从上往下拉

3. 装饰（让背景不单调）：
   形状工具(U) → 椭圆 → 在右上角画一个大的浅色圆
   → 填充白色 → 不透明度 5%
   → Ctrl+T → 旋转30°
   再来2-3个不同大小的圆形点缀

4. 主标题：
   文字工具(T) → "2026 技术开放日"
   → 字号 72pt, 白色, 粗体, 居中
   → 放在画布上1/3位置

5. 副标题：
   文字工具 → "AI重塑开发工作流"
   → 字号 36pt, 浅紫色, 常规
   → 放在主标题下方

6. 分隔线：
   矩形工具 → 画一条细线(宽400px, 高2px)
   → 填充白色 → 不透明度 40%
   → 放在主标题和副标题中间

7. 时间地点信息：
   文字工具 → 拉出一个文字框（下半部分）
   → 输入：
     📅 2026年6月15日 14:00-17:00
     📍 线上直播 + 北京线下会场
     🎙️ 嘉宾：XXX、XXX、XXX
   → 字号 24pt, 白色, 左对齐, 行距 36pt

8. 底部二维码预留区：
   矩形工具 → 160×160px 白色方块 → 右下角
   → 不透明度 20%（留给真实二维码）

9. 导出 → PNG → 完成
```

### 项目5：人物抠图 + 换背景 + 文字排版（综合大项目）

```
难度：⭐⭐⭐⭐ | 复习技能：快速选择、选择并遮住、图层蒙版、文字、调色

需求：把一张人物照片扣出来，放到城市夜景背景上，加上一句英文文案，
      做成一张"有电影感"的海报。

步骤：
1. 打开人物照片和夜景背景两张图

2. 抠图（参考中篇第四章）：
   - 快速选择 → 选人物
   - 选择并遮住 → 处理头发边缘
   - 输出到"新建带有图层蒙版的图层"

3. 把扣好的人物拖到夜景背景图上：
   - 选移动工具(V)
   - 把人物图层从原文件拖到背景文件
   - Ctrl+T 调整人物大小和位置（放在画面右边）

4. 统一色调（让人物融入背景）：
   - 给人物图层加"色彩平衡"调整图层
   - 右键调整图层 → 创建剪贴蒙版(只影响人物)
   - 中间调：加点蓝色，加点青色（匹配夜景的冷色调）
   - 新建图层 → 剪贴蒙版 → 用柔边画笔(硬度0%) → 前景色取天空的蓝色
     → 在人物左侧边缘涂一点 → 不透明度降到30%
     （模拟环境光从左边打过来）

5. 添加文字：
   - 文字工具 → 在画面左侧空白处输入英文文案
   - 字体选一个细衬线体（如Playfair Display）
   - 字号72pt, 白色
   
6. 加文字投影（增强可读性）：
   - 选中文字图层 → 图层面板底部 fx → 投影
   - 不透明度 50%, 距离 5px, 大小 10px

7. 整体调色（最后一步统一氛围）：
   - 图层面板顶部 → ◐ → 色彩平衡
   - 中间调：蓝+5, 青+3
   - 阴影：蓝+10, 青+5
   - 整个画面有了统一的冷色调电影感

8. 加暗角（让视觉聚焦人物）：
   - 新建图层 → 填充黑色
   - 选椭圆选框 → 羽化 100px → 在画面中间画一个椭圆
   - 按Delete → 黑色层中间变透明 → 四周变暗
   - 不透明度降到 40%

9. 导出 → PNG → 完成
```
