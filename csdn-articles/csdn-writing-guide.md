## 二、6 种高产标题公式

### 1. 「一文打通/讲透」系列（深度型）
```
一文打通 + 核心技术点
```
- ✅ 「一文打通事务机制：从锁、Undo Log 到 MVCC 与隔离级别」
- ✅ 「一文讲透 Kafka 高性能四大支柱」
- 适合：MySQL/Redis/Kafka/Linux 等后端基础技术

### 2. 「保姆级/手把手」系列（教程型）
```
保姆级教程 / 手把手 + 从 X 到 Y
```
- ✅ 「保姆级教程：从零搭建你的第一个 AI Agent」
- ✅ 「Python AI 入门：从 Hello World 到图像分类」
- 适合：AI Agent 搭建、工具安装配置、框架入门

### 3. 「告别/替代」系列（痛点型）
```
告别 XX / 不用再 XX + 新方案
```
- ✅ 「告别 frp 和 ngrok：UU 远程端口映射」
- ✅ 「AI 能赚钱？别被割韭菜了！」
- 适合：工具推荐、方案对比、避坑指南

### 4. 「2026 年 X 月横评」系列（对比型）
```
2026 年 X 月 + N 款 + 横评/谁更
```
- ✅ 「2026年5月 AI 编程工具横评：Cursor 3 vs TRAE vs Claude Code」
- ✅ 「AI Agent 工具选型：OpenClaw、Hermes、Codex 怎么选」
- 适合：工具/框架/方案选型

### 5. 「从零开始/进阶系列」系列（连载型）
```
从零开始 / 进阶系列 / Day N + 做什么
```
- ✅ 「从零开始掌握 BP 神经网络：基于 TensorFlow」
- ✅ 「跟着 MDN 学 HTML day_11」
- 适合：系统性学习、长期连载积累粉丝

### 6. 「实战/落地」系列（应用型）
```
技术 + 实战指南/落地之路
```
- ✅ 「AI Agent 落地之路：从 Prompt 工程到 Harness 工程」
- ✅ 「Redis 高并发点赞系统实战」
- 适合：企业级应用、项目经验分享

## 三、4 种高转化文章框架

### 框架 A：保姆级教程（阅读量最稳定，2k-2w）
```
1. 开篇：你遇到了什么问题？
2. 环境/工具准备（配截图）
3. 核心步骤拆解（3-7 步，每步配代码+截图）
4. 完整代码/项目地址
5. 效果展示（截图/GIF）
6. 常见问题 & 解决方案
7. 总结 + 下一步预告
```

### 框架 B：深度解析（收藏率最高，2k-1w）
```
1. 一句话摘要
2. 背景：这个话题为什么重要？
3. 核心概念拆解（2-3 层级）
4. 底层原理/架构分析（配图）
5. 实战验证/数据支撑
6. 局限性讨论（不要说满）
7. 总结 + 展望
```

### 框架 C：横评对比（讨论度最高，1k-8k）
```
1. 评选标准（几个维度？）
2. 逐一介绍（每个 200-300 字）
3. 横向对比表格（关键！必加）
4. 优劣分析
5. 场景化推荐（什么人适合什么）
6. 总结建议
```

### 框架 D：观点洞察（传播性最强，5k-7w+）
```
1. 抛反常观点/争议性认知
2. 数据/案例支撑
3. 多角度论证（3-4 个论点）
4. 反方观点 & 回应
5. 行动建议
6. 金句收尾
```

## 四、内容深度铁律

> CSDN 热门文章最少要到「中层」（有方法、能落地）。
> 深度文章收藏率是普通教程的 3-5 倍。

| 层次 | 特征 | 读者反馈 |
|------|------|---------|
| 表层 | 信息罗列、新闻摘要 | 「知道了，然后呢？」 |
| 中层 | 方法教程、可操作 | 「有用，收藏了」 ✅ |
| 深层 | 原理分析、认知升级 | 「原来如此，转了」 🔥 |

**增加深度的 4 个技巧：**
1. **给数据不给感觉** → ❌「很多人在用」 ✅「阅读量 5.6k，110 赞」
2. **给原理不给步骤** → ❌「运行这个命令」 ✅「这个命令做了三件事：①②③」
3. **给对比不给独白** → ❌「这个方法很好」 ✅「A 耗时 3s/92%，B 耗时 0.5s/88%」
4. **给局限不给夸大** → ❌「完美方案」 ✅「适用：单机<100 万数据」

## 五、发表前自检清单

- [ ] 摘要写了（2-3 句，含关键词）
- [ ] 标签加了（3-5 个）
- [ ] 目录结构清晰（# → ## → ###）
- [ ] 代码块有语言标注 + 注释
- [ ] 有配图或表格（纯文字 > 800 字必配图）
- [ ] 结尾有互动引导（「你觉得呢？」「你用过哪个？」）
- [ ] 全文至少 1-2 个可引用金句
- [ ] 涉及工具/框架标注了版本号
- [ ] 标题 20-35 字、有数字或痛点
